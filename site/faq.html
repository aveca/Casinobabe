FAQ / CASINOBAE

Questions
claires.

Le site contrôle WoW ?

Non. Le site peut afficher les événements transmis par une intégration autorisée, mais WoW reste la source de vérité.

Le browser peut cliquer à ma place ?

Non pour les actions protégées. CasinoBae affiche ACTION_REQUIRED et reprend après confirmation réelle.

Les démos sont-elles réelles ?

Non. Les pages de démonstration sont explicitement DEMO ONLY. Elles ne créent aucun trade ni payout réel.

Quels jeux sont disponibles ?

Le MVP public actuel repose sur High Roll avec le vrai /rand. Les autres jeux doivent réutiliser des événements réellement disponibles.

Y a-t-il un backend public ?

Le dépôt actuel est servi par GitHub Pages. Le contrat bridge est préparé, mais aucun backend fictif n'est présenté comme connecté.

Comment signaler un bug ?

Utilise les Issues du dépôt GitHub avec la version addon, l'état observé et les étapes pour reproduire.
